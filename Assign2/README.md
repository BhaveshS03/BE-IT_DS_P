# Assignment 2

## Description
A CORBA (Common Object Request Broker Architecture) application that provides a string reversal service. The server takes a string and returns its reversed version.

## Files
- ReverseModule.idl : The Interface Definition Language file defining the `Reverse` interface.
- ReverseImpl.java : The implementation of the reverse service.
- ReverseServer.java : The server program that initializes the ORB, POA, and binds the servant.
- ReverseClient.java : The client program that prompts the user for a string and calls the remote service.

## Requirements
- Java 8

## How to Run

### Java
```bash
# Compile the IDL file
idlj -fall ReverseModule.idl

# Compile the Java files
javac *.java ReverseModule/*.java

# Start the CORBA Naming Service (in a separate terminal)
orbd -ORBInitialPort 1050

# Start the server (in a separate terminal)
java ReverseServer -ORBInitialPort 1050 -ORBInitialHost localhost

# Run the client
java ReverseClient -ORBInitialPort 1050 -ORBInitialHost localhost
```

## Code Explanation (Line-by-Line)

### 1. `ReverseModule.idl` (Interface Definition Language)
```idl
module ReverseModule { // Declares a namespace (module) which maps to a Java package
    interface Reverse { // Declares an interface (maps to a Java interface)
        // Defines a method that takes an input string and returns a string
        // 'in' indicates the parameter is passed from client to server
        string reverse_string(in string str); 
    };
};
```

### 2. `ReverseImpl.java` (The Implementation)
```java
import ReverseModule.ReversePOA; // Imports the skeleton class generated by the IDL compiler
import java.lang.String;

// Extends ReversePOA (Portable Object Adapter) to provide the actual server implementation
class ReverseImpl extends ReversePOA {
    ReverseImpl() {
        super(); // Calls the constructor of the parent skeleton class
        System.out.println("Reverse Object Created");
    }

    // Actual implementation of the reverse_string method defined in the IDL
    public String reverse_string(String name) {
        StringBuffer str = new StringBuffer(name); // Use StringBuffer for string manipulation
        str.reverse(); // Built-in method to reverse the string
        return (("Server Send " + str)); // Return the reversed string with a prefix
    }
}
```

### 3. `ReverseServer.java` (The Server Application)
```java
import ReverseModule.*;
import org.omg.CosNaming.*; // Imports for the CORBA Naming Service
import org.omg.CosNaming.NamingContextPackage.*;
import org.omg.CORBA.*; // Core CORBA classes
import org.omg.PortableServer.*; // Classes for the Portable Object Adapter (POA)

class ReverseServer {
    public static void main(String[] args) {
        try {
            // initialize the Object Request Broker (ORB) to manage communications
            org.omg.CORBA.ORB orb = org.omg.CORBA.ORB.init(args, null);

            // get reference to the Root POA and activate its POAManager to allow request processing
            POA rootPOA = POAHelper.narrow(orb.resolve_initial_references("RootPOA"));
            rootPOA.the_POAManager().activate();

            // creating the servant object (the actual implementation logic)
            ReverseImpl rvr = new ReverseImpl();

            // get the CORBA object reference for the servant
            org.omg.CORBA.Object ref = rootPOA.servant_to_reference(rvr);

            System.out.println("Step1");
            // cast (narrow) the generic object reference to the specific Reverse interface
            Reverse h_ref = ReverseModule.ReverseHelper.narrow(ref);
            System.out.println("Step2");

            // get the root naming context from the Naming Service
            org.omg.CORBA.Object objRef = orb.resolve_initial_references("NameService");

            System.out.println("Step3");
            // narrow the naming service reference to a NamingContextExt object
            NamingContextExt ncRef = NamingContextExtHelper.narrow(objRef);

            System.out.println("Step4");

            // Define the name under which the object will be registered
            String name = "Reverse";
            NameComponent path[] = ncRef.to_name(name);
            
            // bind (register) the object reference with the Naming Service using the name "Reverse"
            ncRef.rebind(path, h_ref);

            System.out.println("Reverse Server reading and waiting....");
            
            // Wait for invocations from clients in a continuous loop
            orb.run();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

### 4. `ReverseClient.java` (The Client Application)
```java
// client
import ReverseModule.*;
import org.omg.CosNaming.*;
import org.omg.CosNaming.NamingContextPackage.*;
import org.omg.CORBA.*;
import java.io.*; // For user input

class ReverseClient {
    public static void main(String args[]) {
        Reverse ReverseImpl = null; // Declare reference to the remote interface
        try {
            // initialize the ORB
            org.omg.CORBA.ORB orb = org.omg.CORBA.ORB.init(args, null);
            
            // get the root naming context (connection to the Naming Service)
            org.omg.CORBA.Object objRef = orb.resolve_initial_references("NameService");
            NamingContextExt ncRef = NamingContextExtHelper.narrow(objRef);
            
            // Name of the object we want to look up
            String name = "Reverse";
            
            // resolve the object reference in the naming service and narrow it to the Reverse interface
            ReverseImpl = ReverseHelper.narrow(ncRef.resolve_str(name));
            
            // Prompt user for input
            System.out.println("Enter String=");
            BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
            String str = br.readLine(); // Read input string from the console
            
            // Invoke the remote method reverse_string on the server
            String tempStr = ReverseImpl.reverse_string(str);
            
            // Print the result received from the server
            System.out.println(tempStr);
        } catch (Exception e) {
            e.printStackTrace(); // Handle any communication or naming service errors
        }
    }
}
```
